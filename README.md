# Chevrolet Motors

Chevrolet Motors is an immersive automotive hotsite inspired by the identity, performance, and legacy of Chevrolet.

The project was designed to create a visually striking browsing experience through large-scale automotive imagery, cinematic layouts, smooth navigation, and CSS-based parallax effects. Each section presents a different vehicle or automotive concept while maintaining a consistent visual identity throughout the website.

From iconic performance cars to modern SUVs and electric mobility, the website explores different aspects of the Chevrolet universe through a modern and responsive interface.


---


## Project Overview

Chevrolet Motors was developed as an academic web development project with a focus on creating a complete and visually engaging hotsite using fundamental front-end technologies.

The main objective was to combine structure, design, navigation, imagery, and animation into a single website while applying concepts learned in HTML and CSS.

The website is organized into six main parallax sections, each featuring a different Chevrolet vehicle or automotive concept. Additional pages provide information about the project, Chevrolet's history, contact details, and a real dealership location.

The result is a website designed to feel more like a modern automotive presentation than a traditional informational page.


---


## Vehicle Showcase

The main page features six sections, each with its own visual identity and content.

### Corvette

A representation of Chevrolet's performance heritage, highlighting the Corvette as one of the most recognizable American sports cars.

### Camaro

A section focused on the Camaro's aggressive styling, sporty character, and cultural significance in the automotive world.

### Silverado

A showcase dedicated to Chevrolet's full-size pickup, emphasizing strength, capability, technology, and comfort.

### Tracker

A modern SUV section focused on practicality, technology, comfort, and everyday driving.

### Onix

A compact vehicle showcase emphasizing connectivity, technology, efficiency, and usability.

### Equinox EV

A section representing the transition toward electric mobility, combining modern design, technology, and a vision for the future of driving.

---


## Parallax Experience

One of the main characteristics of the project is its use of the CSS parallax effect.

Each main section uses a large background image that remains visually fixed while the page content moves during scrolling.

This allows the website to achieve a dynamic visual effect without relying on JavaScript or external animation libraries.

For smaller screens, the background behavior is adjusted to provide a better experience and avoid unnecessary performance issues.

## Website Pages

In addition to the main hotsite, the project contains four dedicated internal pages.

### Who We Are

Introduces the Chevrolet Motors concept and explains the purpose of the website and the project.

### Our History

Provides a brief overview of Chevrolet's origins, development, and relevance within the automotive industry.

### Contact

### Address

Displays the location of a Chevrolet dealership in Curitiba, Paraná, Brazil, together with an embedded Google Maps location.

## Navigation

The website includes a fixed navigation menu that allows visitors to quickly move between the main sections.

The footer also provides access to the internal pages:

- Who We Are
- Our History
- Contact
- Address

The navigation structure was designed to keep the website simple, intuitive, and easy to explore.


---


## Responsive Design

The website was designed to adapt to different screen sizes.

Responsive CSS rules modify the layout when the screen becomes smaller, including:

- Navigation positioning
- Font sizes
- Section spacing
- Footer layout
- Background behavior
- Map dimensions
- Content alignment

This allows the website to remain functional and visually consistent across desktop and mobile devices.

## Design Philosophy

The website was created around three main ideas:

### Performance

The visual identity reflects the performance-oriented side of Chevrolet through strong typography, dramatic imagery, and sports car sections.

### Technology

Modern vehicles and electric mobility are represented through clean layouts, responsive design, and contemporary visual elements.

### Identity

The use of dark tones, red highlights, large vehicle photography, and minimal interfaces creates a recognizable automotive aesthetic throughout the website.
